# Coffee fixture

`coffee.jpg` is a JPEG conversion (quality 90, original 600 x 400 resolution) of
[`coffee.png` from scikit-image v0.25.2](https://github.com/scikit-image/scikit-image/blob/v0.25.2/skimage/data/coffee.png).
Photographer: Rachel Michetti. Released under CC0, with no copyright restrictions,
as documented in [`coffee()`](https://github.com/scikit-image/scikit-image/blob/v0.25.2/skimage/data/_fetchers.py).

The private cup-in-hand regression photo is passed through the
`cupInHandFixture` instrumentation argument and is never included in this repository.
