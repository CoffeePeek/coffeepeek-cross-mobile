Полка

Личная полка с кофе, который есть у человека дома. Пачку добавляют сканом с той же жёлтой кнопки, что и чекин. Пачки стоят на полке, их можно переставлять. Закончившаяся пачка уходит в архив, а архив со временем становится историей покупок.

Главные решения

Что предлагаю

Полка живёт во вкладке «Кофе»Вкладка уже про кофе: сейчас там каталог зёрен. Сверху переключатель «Моя полка / Каталог». Своё рядом с каталогом, и каталог помогает заполнить пачку.
Вход с той же кнопки «+»Шторка выбора типа уже есть («В кофейне» / «Дома»). В неё добавляется третий вариант: «Пачку на полку». Новой кнопки не появляется.
Скан — это главное, форма — потомСначала камера и карточка пачки. Название и обжарщика можно оставить на потом: полка показывает пачки картинками.
«Выкинуть» — это не удалениеЗакончившийся кофе уходит в архив с датой и оценкой, на случай с отменой. Удаление есть только для ошибочно добавленных пачек.
Пре-модерация — часть флоуЕсли скан не удался, человек видит причину и подсказку, а не плохую карточку. Есть запасной путь: поправить углы вручную.
Полка кормит чекиныПри чекине «Дома» выбор зёрен начинается с пачек с полки. Так связь с каталогом и учёт расхода появляются без лишних вопросов.

Детали взаимодействия

Жесты, состояния, крайние случаи

СитуацияПоведение
Касание пачкиОткрывает карточку пачки (K): лист снизу на 0,9 высоты, как домашний чекин.
Долгое нажатиеВибрация, пачка поднимается. Перетаскивание по сетке, соседи плавно сдвигаются. Порядок сохраняется сразу и синхронизируется в фоне.
Бросок в «Закончилась»Шторка итога (J). Отмена в снекбаре возвращает пачку на прежнее место.
ДоступностьУ каждой пачки есть действия «Переместить выше / ниже» и «Закончилась» для TalkBack. Перетаскивание — не единственный путь.
Много пачекПолки растут вниз, экран прокручивается. Перетаскивание у края экрана прокручивает список.
Нет сетиСкан и карточка делаются на телефоне. Сохранение ставится в очередь, пачка встаёт на полку с отметкой «синхронизируется».
Первый сканЕсли модели ещё не скачаны — прогресс «Готовим сканер · 25 МБ» до открытия камеры. Отказ от загрузки не теряет фото.
Повтор пачкиСкан той же пачки из каталога, что уже стоит на полке: «Такая уже есть. Добавить вторую?»
УдалениеТолько из меню «⋯» карточки, с подтверждением CoffeePeekDestructiveConfirmationSheet. Для «закончилась» удаление не используется.
Связи с остальным приложением

Полка, чекины и каталог

Чекин «Дома»

  • Выбор зёрен открывается группой «С моей полки» над поиском по каталогу.
  • Чекин с пачкой с полки сохраняет её каталожный coffeeProductSlug (если есть) или название.
  • Доза из чекина (doseGrams) вычитается из веса пачки: отсюда «осталось ≈ 160 г» и мягкая подсказка «Похоже, пачка заканчивается».

Каталог «Кофе»

  • В карточке кофе из каталога: «Есть на полке» или «Добавить на полку» (без скана, с фото каталога).
  • В архиве «Купить снова» ведёт к предложениям продавцов (CoffeeOffer).
  • Связь с каталогом делает полку полезнее, но не обязательна.

Профиль и лента

  • В профиле — строка «Полка · 7 пачек» с тремя миниатюрами, ведёт во вкладку «Кофе».
  • Видимость полки другим людям — отдельное решение, по умолчанию полка приватная.
  • В ленту пачки сами не попадают, только чекины.

Открытые вопросы

Где именно живёт полка?Предлагаю переключатель внутри вкладки «Кофе». Альтернативы — отдельная вкладка (их уже пять) или раздел в профиле. Рекомендую «Кофе».
Хранить на сервере или только на телефоне?Правила проекта требуют серверного хранения для личных данных вроде избранного. Нужны API полки и загрузка картинки ~100 КБ. Рекомендую сервер с самого начала.
Спрашивать оценку при «Закончилась»?Даёт данные для архива и рекомендаций, но добавляет шаг. Рекомендую спрашивать, с «Пропустить».
Как доставлять модели?U2-Net-p (4,6 МБ) можно встроить в приложение. MI-GAN (28 МБ) — в приложение или скачивать при первом скане. Отложено вместе с оптимизацией.
Техническая рамка

Как это ложится в проект

Модули

  • feature/shelf/{api,domain,data,impl} по правилам миграции
  • Сканер — отдельная граница: чистое ядро из пробы (imaging/) переезжает как есть, ONNX-обвязка — в data
  • Шторку «+» расширяет композиция приложения, а не сама фича

Данные

  • Пачка: id, картинка, название, обжарщик, slug каталога, вес, помол, даты (добавлена, обжарка, закончилась), позиция, статус, оценка
  • API: список полки, архив, создание, изменение, порядок, «закончилась», удаление

Аналитика

  • Новый вид в шторке: check_in_kind_selected с видом shelf_bag
  • shelf_scan_result (вердикт, причины, время), shelf_bag_added, shelf_bag_reordered, shelf_bag_finished, shelf_archive_opened
  • Метрики пре-модерации — для калибровки порогов
