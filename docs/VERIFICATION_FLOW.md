# Флоу проверки после баг-фиксов (2026-11-10)

Сборка: ветка `fix/ui-feedback-fixes` (коммит с полным бэклогом). Android —
`directSandbox` (`com.coffeepeek.sandbox`, фейковый бэкенд, «без сети»),
проверена сборка и запуск на эмуляторе и на устройстве Pixel 7. iOS — сборка
для симулятора; на устройстве iPhone с установленным приложением пройтись по
тому же списку.

Скриншоты-улики проблем (до/после) — `~/StudioProjects/coffeepeek-ui-evidence/`.

## 1. Сердечки и лайки

1. Поиск → карточка кофейни → нажать сердечко в углу фото: **вспыхивает только
   сердце** (масштаб-поп + плавная перекраска), карточка и фон не реагируют.
2. Открыть кофейню → сердечко в стеклянном диске сверху: диск не темнеет и не
   скейлится, реагирует только сердце.
3. Лента → пост → «полезно»: рипл ограничен кругом вокруг сердца, строка со
   счётчиком остаётся рабочей зоной касания.
4. Лайк своих постов в ленте — разрешён (задуманное поведение, не баг).

## 2. Полка и профиль (дёрганый возврат)

1. Профиль → Полка → открыть пачку → «Назад»: недельная лента в шапке сразу
   показывает дни и пачку, **без серых скелетон-плиток** (улика
   `before/shelf_return_skeleton_flash.png`).
2. На Полке открыть пачку → Назад несколько раз подряд: сетка не мигает, счёт
   «7 пачек» не прыгает.
3. Публичный профиль другого владельца пачек (поиск → владелец → полка) →
   открыть пачку → Назад: то же — без скелетон-вспышки.

## 3. Форма чекина (главный регресс-риск)

1. Открыть форму чекина при наличии черновика → редактировать поля: драфт
   сохраняется (при выходе и повторном входе поля восстановлены).
2. Отправить чекин с включённой сетью (sandbox: «Заварить чашку» на пачке
   недоступен — использовать «Чекин» на кофейне) → успех: «Опубликовано»,
   ошибки драфта нет.
3. Отправка при сбое сети: форма показывает ошибку сервера/сети и **не**
   утверждает «доставка не подтверждена» для однозначного отказа (400/403);
   редактирование остаётся заблокированным только для действительно
   неопределённых исходов.
4. Сломать хранилище драфтов сложно вручную — регресс закрывают юнит-тесты
   (`ShopCheckInCreateViewModelTest`); вручную достаточно п.1–2.

## 4. Уведомления

1. Открыть шторку уведомлений с несколькими непрочитанными → прокрутить вниз,
   нажать «Ещё» → тапнуть по непрочитанному уведомлению: **подгруженные
   страницы не схлопываются**, список не дёргается, непрочитанные остаются.
2. Бейдж с количеством уведомлений плавно появляется/исчезает.

## 5. Бизнес-режим (на аккаунте владельца)

1. Включить бизнес-режим при включённой сети → настройки → выключить → снова
   включить: лента/вкладки не пересоздаются с нуля (карта и скролл сохраняются).
2. В бизнес-режиме открыть публикацию → подтвердить → «Отмена» в диалоге
   работает и во время сохранения.
3. Слайд между вкладками в бизнес-режиме (Бизнес ↔ Настройки) направлен по
   позиции вкладок, а не всегда влево.

## 6. Профиль и публичный профиль

1. Профиль → вкладки Чекины/Подборки/Полка: underline-индикатор плавно
   скользит, контент сменяется с плавной перекраской.
2. Открыть публичный профиль → заблокировать автора из его чекина → вернуться:
   профиль не мигает полным скелетоном (stale-while-revalidate).
3. Полка публичного владельца → пачка → Назад: без скелетон-вспышки.
4. В шапке истории при фильтре «Дома» подпись не показывает «0 кофеен».

## 7. Настройки и город

1. Настройки → Город при сбое каталога (sandbox «без сети»): строка не
   «переписывает» сохранённый город; приложение не падает.
2. Выбор языка: галочка плавно появляется.
3. iOS debug со включёнными проверками обновлений — «Проверить обновления»
   больше не крутит фейковый спиннер без результата (на сборках, где проверки
   выключены, строка скрыта/неактивна после фикса `canCheckForUpdates`).

## 8. Прочее (быстрая проба)

1. Лента у гостя с пустыми постами: виден CTA «Войти, чтобы читать ленту» и
   оформленное empty-состояние.
2. Детали кофе → «к продавцу» с битым URL: приложение не падает.
3. Гостевой онбординг: автопрокрутка останавливается на последнем слайде.
4. Deep link `...?checkin=1&checkin=1` открывает гостевой чекин-флоу.
5. Редактор подборки: 409 → «Повторить» просит подтверждение перед потерей
   правок.

## 9. iOS-специфика

1. Сборка: `xcodebuild -project iosApp/iosApp.xcodeproj -scheme iosApp
   -configuration Debug -destination 'platform=iOS Simulator,name=iPhone 17 Pro'
   CODE_SIGNING_ALLOWED=NO build` — зелёная.
2. Пройти разделы 1–8 на симуляторе/устройстве: таб-бар и контролы нативные,
   карточки/формы — общий Compose-слой.
3. Сканер пачки (полка → добавить → камера): тяжёлый MI-GAN-этап при OOM больше
   не роняет приложение — показать «Переснять».
4. Тёмная тема и светлый шрифт-скейл (настройки системы) — сердечки, бейджи,
   табы выглядят корректно в обеих темах.
